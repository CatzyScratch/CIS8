**ABOUT CIS8 ⌨️🖥️**

CIS8 is a programming language designed for the LIS8 - an 8-bit CPU I made in scratch.<br><br>
It has just **8 keywords** and **every instruction is 7 - 8 characters long**.
I've also made a custom python compiler which can convert .cis8 files into .bin files.

**Its completely open source meaning you can do whatever you want with it or the compiler.**<br><br>
A Example programs:
<br><br>
**_/This is a incrementer program, it increments memory address 2 by 1 every tick\\<br>
ins 01,01<br>
add 01,02<br>
jmp 01,00_**
